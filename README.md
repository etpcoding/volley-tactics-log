# VC Haslach Spiellog

Erstelle mir eine App die sich rund um um Volleyball zieht, ich möchte ein Modul für eine kaderübersicht wo ich Spieler hinzufügen kann und wieder löschen, ein Modul für aufstellungstaktiken zum besprechen von Spielzügen und ein Modul wo ich während des Spieltages Punkte eintragen kannn, wie sie gemacht wurden und wer sie gemacht hat, wer welchen Fehler gemacht hat und mit welcher angrifstechnik sie gemacht wurden
